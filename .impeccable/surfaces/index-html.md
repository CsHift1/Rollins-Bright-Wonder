# Portfolio surface brief

## Scope and visitor mode

The static single-page personal portfolio. Mode: Experience.

## Audience, job, and action

Visitors want to understand Rollins's electrical engineering studies, freelance web work, skills, and current projects. They can follow the page route, try the interactive learning demonstrations, open the real portfolio repository, or use the published contact links.

## Proof and content

Use the existing profile, study, project, and contact copy as the source of truth. The portfolio repository is the published project; electrical study notes and the Python learning lab remain explicitly in progress.

## Constraints

Keep the site responsive, static, build-free, and compatible with GitHub Pages. Preserve the existing public email, phone/WhatsApp, LinkedIn, location, and repository routes. Do not invent completed work or credentials.

## Direction and memorable moment

The Field Journal Map uses pale survey terrain, contour lines, and a numbered purple route to connect the visitor's choices. The first viewport pairs an oversized engineering-and-web headline with a live three-phase waveform. The navigation course remains selectable independently of the page content.

## Open decisions

- Add repositories or live demos to the in-progress project entries only when they exist.
